There is one API host: **production**. Every request in this documentation goes to it.

## Host

| | Value |
|---|---|
| API base URL | `https://api.futuur.com/v2.0` |
| OpenAPI schema | `https://api.futuur.com/docs/schema/` |
| Trading halt flag | `GET /v2.0/trading-status/` (no auth) returns `trading_halted` |

Include the version in every request path. Paths end with a trailing slash, for example `POST /v2.0/orders/`.

## What is live

| Feature | Status |
|---|---|
| HMAC-authenticated REST API. See [Authentication](/authentication) | Live |
| Events, markets, order book, wagers, balances | Live |
| Limit orders (`gtc` and `ioc`), cancel, batch cancel, cancel all | Live |
| Realtime WebSocket gateway. See [WebSocket overview](/api-reference/websocket/overview) | Live |
