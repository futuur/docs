---
title: 'Retrieve event'
description: 'Get detailed information about a specific event by its ID.'
---

Retrieve full details for a specific prediction market event, including all associated markets (outcomes).

## Endpoint

```
GET https://api.futuur.com/v2.0/events/{id}/
```

## Authentication

<Note>
  This endpoint supports optional HMAC authentication. Authenticated requests may return additional user-specific data.
</Note>

## Request

<ParamField path="id" type="integer" required>
  A unique integer value identifying this event.
</ParamField>

## Response

Returns the full event detail object.

<ResponseField name="id" type="integer" required>
  Unique event identifier.
</ResponseField>

<ResponseField name="title" type="string" required>
  The prediction question.
</ResponseField>

<ResponseField name="slug" type="string" required>
  URL-friendly identifier.
</ResponseField>

<ResponseField name="status" type="string" required>
  Current state: `open`, `stopped`, `resolved`, `cancelled`, `paused`, or `reversed`.
</ResponseField>

<ResponseField name="markets" type="array" required>
  Array of market (outcome) objects for this event.
</ResponseField>

<ResponseField name="description" type="string">
  Full question details and resolution criteria.
</ResponseField>

<ResponseField name="bet_end_date" type="string">
  ISO 8601 datetime when betting closes.
</ResponseField>

<ResponseField name="resolve_date" type="string">
  ISO 8601 datetime when the event was resolved.
</ResponseField>

## Example

<CodeGroup>

```bash cURL
curl --request GET \
  --url "https://api.futuur.com/v2.0/events/42/" \
  --header "Key: YOUR_PUBLIC_KEY" \
  --header "Timestamp: 1712534400" \
  --header "HMAC: YOUR_HMAC_SIGNATURE"
```

```python Python
import requests

response = requests.get(
    "https://api.futuur.com/v2.0/events/42/",
    headers={
        "Key": "YOUR_PUBLIC_KEY",
        "Timestamp": "1712534400",
        "HMAC": "YOUR_HMAC_SIGNATURE"
    }
)

print(response.json())
```
