---
title: 'Retrieve event'
description: 'Retrieve detailed information about a single event by its ID.'
---

Retrieve full details for a specific prediction market event, including all associated markets (outcomes), resolution criteria, and current status.

## Endpoint

```
GET https://api.futuur.com/v2.0/events/{id}/
```

## Authentication

<Note>
  This endpoint supports optional HMAC authentication. Authenticated requests may receive additional user-specific data.
</Note>

## Request

<ParamField path="id" type="integer" required>
  The unique identifier of the event to retrieve.
</ParamField>

## Response

Returns an `EventDetail` object with full event information.

<ResponseField name="id" type="integer" required>
  Unique event identifier.
</ResponseField>

<ResponseField name="title" type="string" required>
  The prediction question.
</ResponseField>

<ResponseField name="slug" type="string" required>
  URL-friendly identifier.
</ResponseField>

<ResponseField name="status" type="string" required>
  Current state: `open`, `stopped`, `resolved`, `cancelled`, `paused`, or `reversed`.
</ResponseField>

<ResponseField name="category" type="object[]" required>
  Array of category objects the event belongs to.
</ResponseField>

<ResponseField name="markets" type="object[]" required>
  Array of market (outcome) objects for this event.
</ResponseField>

<ResponseField name="bet_end_date" type="string">
  ISO 8601 datetime when betting closes.
</ResponseField>

<ResponseField name="resolve_date" type="string">
  ISO 8601 datetime when the event was resolved.
</ResponseField>

<ResponseField name="description" type="string">
  Full question details and resolution criteria.
</ResponseField>

## Example

<CodeGroup>

```bash cURL
curl --request GET \
  --url "https://api.futuur.com/v2.0/events/1234/"
```

```python Python
import requests

response = requests.get("https://api.futuur.com/v2.0/events/1234/")
event = response.json()
print(event)
```

```javascript JavaScript
const response = await fetch("https://api.futuur.com/v2.0/events/1234/");
const event = await response.json();
console.log(event);
```
