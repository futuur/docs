---
title: 'Retrieve event'
description: 'Retrieve detailed information about a single event by its ID.'
---

Retrieve full details for a specific prediction market event, including all associated markets (outcomes), resolution criteria, and metadata.

## Endpoint

```
GET https://api.futuur.com/v2.0/events/{id}/
```

## Authentication

<Note>
  This endpoint requires HMAC authentication. Include the `Key`, `Timestamp`, and `HMAC` headers on every request. See the [authentication guide](/authentication) for signing instructions.
</Note>

## Request

<ParamField path="id" type="integer" required>
  The unique identifier of the event to retrieve.
</ParamField>

## Response

Returns an `EventDetail` object with comprehensive event information.

<ResponseField name="id" type="integer" required>
  Unique event identifier.
</ResponseField>

<ResponseField name="title" type="string" required>
  The prediction question.
</ResponseField>

<ResponseField name="slug" type="string" required>
  URL-friendly identifier.
</ResponseField>

<ResponseField name="status" type="string" required>
  Current state: `open`, `stopped`, `resolved`, `cancelled`, `paused`, or `reversed`.
</ResponseField>

<ResponseField name="description" type="string">
  Full question details and resolution criteria.
</ResponseField>

<ResponseField name="category" type="object[]">
  Array of category objects the event belongs to.
</ResponseField>

<ResponseField name="markets" type="object[]" required>
  Array of market (outcome) objects for this event.
</ResponseField>

<ResponseField name="bet_end_date" type="string">
  ISO 8601 datetime when betting closes.
</ResponseField>

<ResponseField name="resolve_date" type="string">
  ISO 8601 datetime when the event was resolved.
</ResponseField>

<ResponseField name="resolution_mode" type="string">
  How markets resolve within the event (linked prices or independent).
</ResponseField>

## Example

<CodeGroup>

```bash cURL
curl --request GET \
  --url "https://api.futuur.com/v2.0/events/1234/" \
  --header "Key: YOUR_PUBLIC_KEY" \
  --header "Timestamp: 1712534400" \
  --header "HMAC: YOUR_HMAC_SIGNATURE"
```

```python Python
import requests

response = requests.get(
    "https://api.futuur.com/v2.0/events/1234/",
    headers={
        "Key": "YOUR_PUBLIC_KEY",
        "Timestamp": "1712534400",
        "HMAC": "YOUR_HMAC_SIGNATURE"
    }
)
print(response.json())
```
