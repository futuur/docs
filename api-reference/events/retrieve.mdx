---
title: 'Retrieve event'
description: 'Get detailed information about a specific prediction market event.'
---

Retrieve detailed information about a single event, including its markets (outcomes).

## Endpoint

```
GET https://api.futuur.com/v2.0/events/{id}/
```

## Authentication

<Note>
  This endpoint supports HMAC authentication. Include the `Key`, `Timestamp`, and `HMAC` headers to access user-specific data. See the [authentication guide](/authentication) for signing instructions.
</Note>

## Request

<ParamField path="id" type="integer" required>
  A unique integer value identifying the event.
</ParamField>

## Response

Returns the full event object with all its markets.

<ResponseField name="id" type="integer" required>
  Unique event identifier.
</ResponseField>

<ResponseField name="title" type="string" required>
  The prediction question.
</ResponseField>

<ResponseField name="slug" type="string" required>
  URL-friendly identifier.
</ResponseField>

<ResponseField name="status" type="string" required>
  Event status: `open`, `stopped`, `resolved`, `cancelled`, `paused`, or `reversed`.
</ResponseField>

<ResponseField name="markets" type="array" required>
  Array of market (outcome) objects for this event.
</ResponseField>

<ResponseField name="description" type="string">
  Full question details and resolution criteria.
</ResponseField>

<ResponseField name="bet_end_date" type="string">
  ISO 8601 datetime when betting closes.
</ResponseField>

<ResponseField name="resolve_date" type="string">
  ISO 8601 datetime when the event was resolved.
</ResponseField>

## Example

<CodeGroup>

```bash cURL
curl "https://api.futuur.com/v2.0/events/12345/" \
  -H "Key: YOUR_PUBLIC_KEY" \
  -H "Timestamp: 1712500000" \
  -H "HMAC: YOUR_HMAC_SIGNATURE"
```

```python Python
import requests

response = requests.get(
    "https://api.futuur.com/v2.0/events/12345/",
    headers={
        "Key": "YOUR_PUBLIC_KEY",
        "Timestamp": "1712500000",
        "HMAC": "YOUR_HMAC_SIGNATURE",
    },
)

event = response.json()
print(f"Event: {event['title']}")
for market in event["markets"]:
    print(f"  Market: {market['title']} - Price: {market['price']}")
```
