---
title: 'Event actions'
description: 'List all trading actions (wagers) for a specific event.'
---

Retrieve a list of all trading actions for an event. Real money actions have user information anonymized.

## Endpoint

```
GET https://api.futuur.com/v2.0/events/{id}/actions/
```

## Authentication

<Note>
  This endpoint requires HMAC authentication. Include the `Key`, `Timestamp`, and `HMAC` headers on every request. See the [authentication guide](/authentication) for signing instructions.
</Note>

## Request

<ParamField path="id" type="integer" required>
  A unique integer value identifying the event.
</ParamField>

<ParamField query="aggregate_by_orders" type="boolean" default="true">
  When `true`, aggregates actions by order.
</ParamField>

<ParamField query="currency_mode" type="string">
  Filter by currency mode. One of `play_money` or `real_money`.
</ParamField>

<ParamField query="following" type="boolean" default="false">
  When `true`, returns only actions from users you follow.
</ParamField>

<ParamField query="my_bets" type="boolean" default="false">
  When `true`, returns only your own actions.
</ParamField>

<ParamField query="search" type="string">
  Full-text search query. Between 1 and 100 characters.
</ParamField>

## Response

Returns a list of wager action objects.

## Example

<CodeGroup>

```bash cURL
curl -G "https://api.futuur.com/v2.0/events/12345/actions/" \
  --data-urlencode "currency_mode=play_money" \
  -H "Key: YOUR_PUBLIC_KEY" \
  -H "Timestamp: 1712500000" \
  -H "HMAC: YOUR_HMAC_SIGNATURE"
```

```python Python
import requests

response = requests.get(
    "https://api.futuur.com/v2.0/events/12345/actions/",
    params={"currency_mode": "play_money"},
    headers={
        "Key": "YOUR_PUBLIC_KEY",
        "Timestamp": "1712500000",
        "HMAC": "YOUR_HMAC_SIGNATURE",
    },
)

actions = response.json()
print(actions)
```
