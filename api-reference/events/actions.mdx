---
title: 'Event actions'
description: 'List all actions (bets) for a specific event.'
---

Retrieve a list of all wager actions for a specific event. Real money actions have user information anonymized.

## Endpoint

```
GET https://api.futuur.com/v2.0/events/{id}/actions/
```

## Authentication

<Note>
  This endpoint supports optional HMAC authentication. Include the `Key`, `Timestamp`, and `HMAC` headers to access user-specific filters. See the [authentication guide](/authentication) for signing instructions.
</Note>

## Request

<ParamField path="id" type="integer" required>
  The unique identifier of the event.
</ParamField>

<ParamField query="aggregate_by_orders" type="boolean" default="true">
  When `true`, aggregates actions by orders.
</ParamField>

<ParamField query="currency_mode" type="string">
  Filter by currency mode. One of `play_money` or `real_money`.
</ParamField>

<ParamField query="following" type="boolean" default="false">
  When `true`, returns only actions from users you follow.
</ParamField>

<ParamField query="my_bets" type="boolean" default="false">
  When `true`, returns only your own bets.
</ParamField>

<ParamField query="search" type="string">
  Full-text search query. Maximum 100 characters.
</ParamField>

## Response

Returns a `WagerAction` object containing the list of actions.

## Example

<CodeGroup>

```bash cURL
curl --request GET \
  --url "https://api.futuur.com/v2.0/events/1234/actions/?currency_mode=play_money" \
  --header "Key: pk_live_abc123def456" \
  --header "Timestamp: 1712534400" \
  --header "HMAC: 3a9f2c1b...sha512signature"
```

</CodeGroup>
