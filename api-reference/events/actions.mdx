---
title: 'Event actions'
description: 'List all actions (trades) for a specific event.'
---

Retrieve a list of all trading actions that have occurred on a specific event. Real money actions have user information anonymized.

## Endpoint

```
GET https://api.futuur.com/v2.0/events/{id}/actions/
```

## Authentication

<Note>
  This endpoint supports optional HMAC authentication. Include the `Key`, `Timestamp`, and `HMAC` headers to access user-specific filters.
</Note>

## Request

<ParamField path="id" type="integer" required>
  A unique integer value identifying this event.
</ParamField>

<ParamField query="aggregate_by_orders" type="boolean" default="true">
  When `true`, aggregates actions by order.
</ParamField>

<ParamField query="currency_mode" type="string">
  Filter by currency mode. One of `play_money` or `real_money`.
</ParamField>

<ParamField query="following" type="boolean" default="false">
  When `true`, returns only actions from users you follow.
</ParamField>

<ParamField query="my_bets" type="boolean" default="false">
  When `true`, returns only your own actions.
</ParamField>

<ParamField query="search" type="string">
  Full-text search query. Maximum 100 characters.
</ParamField>

## Response

Returns a list of wager action objects.

## Example

<CodeGroup>

```bash cURL
curl --request GET \
  --url "https://api.futuur.com/v2.0/events/42/actions/?currency_mode=play_money" \
  --header "Key: YOUR_PUBLIC_KEY" \
  --header "Timestamp: 1712534400" \
  --header "HMAC: YOUR_HMAC_SIGNATURE"
```

</CodeGroup>
