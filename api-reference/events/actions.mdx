---
title: 'Event actions'
description: 'List all actions (trades) for a specific event.'
---

Retrieve a list of all actions (trades) that have occurred on a specific event. Real money actions have user information anonymized.

## Endpoint

```
GET https://api.futuur.com/v2.0/events/{id}/actions/
```

## Authentication

<Note>
  This endpoint supports optional HMAC authentication. Authenticated requests can use filters like `my_bets` and `following`.
</Note>

## Request

<ParamField path="id" type="integer" required>
  The unique identifier of the event.
</ParamField>

<ParamField query="aggregate_by_orders" type="boolean" default="true">
  When `true`, aggregates actions by order.
</ParamField>

<ParamField query="currency_mode" type="string">
  Filter by currency mode. One of `play_money`, `real_money`, or empty string for all.
</ParamField>

<ParamField query="following" type="boolean" default="false">
  When `true`, returns only actions from users you follow.
</ParamField>

<ParamField query="my_bets" type="boolean" default="false">
  When `true`, returns only your own actions on this event.
</ParamField>

<ParamField query="search" type="string">
  Full-text search query. Maximum 100 characters.
</ParamField>

## Response

Returns a `WagerAction` object containing the list of actions.

## Example

<CodeGroup>

```bash cURL
curl --request GET \
  --url "https://api.futuur.com/v2.0/events/1234/actions/?currency_mode=play_money"
```

```python Python
import requests

response = requests.get(
    "https://api.futuur.com/v2.0/events/1234/actions/",
    params={"currency_mode": "play_money"}
)

actions = response.json()
print(actions)
```

</CodeGroup>
