---
title: 'Event actions'
description: 'List all trading actions (wager activity) for an event.'
---

Retrieve a list of all trading actions (wagers) that have occurred on an event. Real money actions have user information anonymized.

## Endpoint

```
GET https://api.futuur.com/v2.0/events/{id}/actions/
```

## Authentication

<Note>
  This endpoint supports optional HMAC authentication. When authenticated, you can filter to show only your own bets.
</Note>

## Request

<ParamField path="id" type="integer" required>
  A unique integer value identifying the event.
</ParamField>

<ParamField query="aggregate_by_orders" type="boolean" default="true">
  When `true`, aggregates actions by order.
</ParamField>

<ParamField query="currency_mode" type="string">
  Currency mode to filter actions. One of `play_money` or `real_money`.
</ParamField>

<ParamField query="following" type="boolean" default="false">
  When `true`, returns only actions from users you follow.
</ParamField>

<ParamField query="my_bets" type="boolean" default="false">
  When `true`, returns only your own actions. Requires authentication.
</ParamField>

<ParamField query="search" type="string">
  Full-text search query. Maximum 100 characters.
</ParamField>

## Response

Returns an array of wager action objects.

## Example

<CodeGroup>

```bash cURL
curl -G "https://api.futuur.com/v2.0/events/12345/actions/" \
  --data-urlencode "currency_mode=play_money" \
  -H "Key: YOUR_PUBLIC_KEY" \
  -H "Timestamp: 1712500000" \
  -H "HMAC: YOUR_HMAC_SIGNATURE"
```

```python Python
import requests

response = requests.get(
    "https://api.futuur.com/v2.0/events/12345/actions/",
    params={
        "currency_mode": "play_money",
        "my_bets": True,
    },
    headers={
        "Key": "YOUR_PUBLIC_KEY",
        "Timestamp": "1712500000",
        "HMAC": "YOUR_HMAC_SIGNATURE",
    },
)

actions = response.json()
for action in actions:
    print(action)
```
