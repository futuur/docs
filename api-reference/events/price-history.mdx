---
title: 'Price history'
description: 'Get historical price data for all markets in an event.'
---

Retrieve price history for an event's markets over a specified time interval. Use this data to chart price movements and analyze market trends.

## Endpoint

```
GET https://api.futuur.com/v2.0/events/{id}/price_history/
```

## Authentication

No authentication required.

## Request

<ParamField path="id" type="integer" required>
  The unique identifier of the event.
</ParamField>

<ParamField query="currency_mode" type="string" required>
  The currency mode for price data. One of `play_money` or `real_money`.
</ParamField>

<ParamField query="time_interval" type="string">
  Time range for the price history. One of `day`, `week`, `month`, `year`, or `all_time`.
</ParamField>

## Response

Returns an array of price history data points for each market in the event.

## Example

<CodeGroup>

```bash cURL
curl -G "https://api.futuur.com/v2.0/events/12345/price_history/" \
  --data-urlencode "currency_mode=play_money" \
  --data-urlencode "time_interval=week"
```

```python Python
import requests

response = requests.get(
    "https://api.futuur.com/v2.0/events/12345/price_history/",
    params={
        "currency_mode": "play_money",
        "time_interval": "week",
    },
)

price_history = response.json()
print(price_history)
```
