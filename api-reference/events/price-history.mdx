---
title: 'Price history'
description: 'Retrieve historical price data for an event.'
---

Retrieve price history for all markets within a specific event. Use this to build charts or analyze price movements over time.

## Endpoint

```
GET https://api.futuur.com/v2.0/events/{id}/price_history/
```

## Authentication

<Note>
  This endpoint does not require authentication.
</Note>

## Request

<ParamField path="id" type="integer" required>
  The unique identifier of the event.
</ParamField>

<ParamField query="currency_mode" type="string" required>
  Currency mode for the price data. One of `play_money` or `real_money`.
</ParamField>

<ParamField query="time_interval" type="string">
  Time interval for data aggregation. One of `day`, `week`, `month`, `year`, or `all_time`.
</ParamField>

## Response

Returns price history data for all markets in the event.

## Example

<CodeGroup>

```bash cURL
curl --request GET \
  --url "https://api.futuur.com/v2.0/events/1234/price_history/?currency_mode=play_money&time_interval=week"
```

```python Python
import requests

response = requests.get(
    "https://api.futuur.com/v2.0/events/1234/price_history/",
    params={
        "currency_mode": "play_money",
        "time_interval": "week"
    }
)

print(response.json())
```
