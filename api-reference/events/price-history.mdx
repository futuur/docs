---
title: 'Price history'
description: 'Retrieve historical price data for an event.'
---

Get price history for all markets within an event over a specified time interval.

## Endpoint

```
GET https://api.futuur.com/v2.0/events/{id}/price_history/
```

## Authentication

<Note>
  This endpoint does not require authentication.
</Note>

## Request

<ParamField path="id" type="integer" required>
  A unique integer value identifying this event.
</ParamField>

<ParamField query="currency_mode" type="string" required>
  Currency mode for price data. One of `play_money` or `real_money`.
</ParamField>

<ParamField query="time_interval" type="string">
  Time interval for the price history. One of `day`, `week`, `month`, `year`, or `all_time`.
</ParamField>

## Response

Returns historical price data points for each market in the event.

## Example

<CodeGroup>

```bash cURL
curl --request GET \
  --url "https://api.futuur.com/v2.0/events/42/price_history/?currency_mode=play_money&time_interval=week"
```

```python Python
import requests

response = requests.get(
    "https://api.futuur.com/v2.0/events/42/price_history/",
    params={
        "currency_mode": "play_money",
        "time_interval": "week"
    }
)

print(response.json())
```
