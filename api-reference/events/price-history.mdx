---
title: 'Price history'
description: 'Get historical price data for an event over a specified time interval.'
---

Retrieve price history for all markets within an event. Use this to display price charts or analyze market movements over time.

## Endpoint

```
GET https://api.futuur.com/v2.0/events/{id}/price_history/
```

## Authentication

No authentication is required for this endpoint.

## Request

<ParamField path="id" type="integer" required>
  The unique identifier of the event.
</ParamField>

<ParamField query="currency_mode" type="string" required>
  The currency mode to query. One of `play_money` or `real_money`.
</ParamField>

<ParamField query="time_interval" type="string">
  Time range for the price history. One of `day`, `week`, `month`, `year`, or `all_time`.
</ParamField>

## Response

Returns price history data points for each market in the event.

## Example

<CodeGroup>

```bash cURL
curl --request GET \
  --url "https://api.futuur.com/v2.0/events/1234/price_history/?currency_mode=play_money&time_interval=week"
```

```python Python
import requests

response = requests.get(
    "https://api.futuur.com/v2.0/events/1234/price_history/",
    params={
        "currency_mode": "play_money",
        "time_interval": "week"
    }
)
print(response.json())
```
