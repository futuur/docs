---
title: 'Price history'
description: 'Get historical price data for an event.'
---

Retrieve historical price data for all markets within an event.

## Endpoint

```
GET https://api.futuur.com/v2.0/events/{id}/price_history/
```

## Authentication

No authentication required.

## Request

<ParamField path="id" type="integer" required>
  A unique integer value identifying the event.
</ParamField>

<ParamField query="currency_mode" type="string" required>
  Currency mode for price history. One of `play_money` or `real_money`.
</ParamField>

## Response

Returns historical price data points for the event's markets.

## Example

<CodeGroup>

```bash cURL
curl -G "https://api.futuur.com/v2.0/events/12345/price_history/" \
  --data-urlencode "currency_mode=play_money"
```

```python Python
import requests

response = requests.get(
    "https://api.futuur.com/v2.0/events/12345/price_history/",
    params={
        "currency_mode": "play_money",
    },
)

price_history = response.json()
print(price_history)
```
