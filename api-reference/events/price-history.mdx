---
title: 'Price history'
description: 'Retrieve historical price data for an event.'
---

Retrieve price history for all markets within an event over a specified time interval.

## Endpoint

```
GET https://api.futuur.com/v2.0/events/{id}/price_history/
```

## Authentication

This endpoint does not require authentication.

## Request

<ParamField path="id" type="integer" required>
  The unique identifier of the event.
</ParamField>

<ParamField query="currency_mode" type="string" required>
  Currency mode for the price history. One of `play_money` or `real_money`.
</ParamField>

<ParamField query="time_interval" type="string">
  Time interval for the price history. One of `day`, `week`, `month`, `year`, or `all_time`.
</ParamField>

## Response

Returns price history data for the event's markets.

## Example

<CodeGroup>

```bash cURL
curl -G "https://api.futuur.com/v2.0/events/12345/price_history/" \
  --data-urlencode "currency_mode=play_money" \
  --data-urlencode "time_interval=week"
```

```python Python
import requests

response = requests.get(
    "https://api.futuur.com/v2.0/events/12345/price_history/",
    params={
        "currency_mode": "play_money",
        "time_interval": "week",
    },
)

price_history = response.json()
print(price_history)
```
