---
title: "Event live data"
description: "Fetch up-to-date event details for live markets without authentication."
---

Retrieve the latest event details for a live market. This endpoint returns the same `EventDetail` shape as [Retrieve event](/api-reference/events/retrieve), but is intended for polling live scoreboards, in-play markets, and other frequently updating event data.

## Endpoint

```
GET https://api.futuur.com/events/{id}/live_data/
```

## Authentication

No authentication is required for this endpoint.

## Parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the event.
</ParamField>

## Response

Returns an `EventDetail` object. See [Retrieve event](/api-reference/events/retrieve) for the full field reference, including `status`, `markets`, `resolution_mode`, and volume fields.

## Example

```bash cURL
curl --request GET \
  --url "https://api.futuur.com/events/1023/live_data/"
```
