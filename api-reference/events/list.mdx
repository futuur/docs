---
title: 'List events'
description: 'Retrieve a paginated list of prediction market events with optional filters.'
---

Retrieve a list of prediction market events. Use query parameters to filter by category, search term, currency mode, and other criteria.

## Endpoint

```
GET https://api.futuur.com/v2.0/events/
```

## Authentication

<Note>
  This endpoint does not require authentication. You can call it without HMAC headers.
</Note>

## Request

<ParamField query="bet_end_date_after" type="string">
  Inclusive lower bound for `bet_end_date`, ISO 8601 with a timezone (for example `2026-11-01T00:00:00Z`). Events without `bet_end_date` are excluded. Combines with the list status window: open and pending resolution, unless `live`, `resolved_only`, or `pending_resolution` is set.
</ParamField>

<ParamField query="bet_end_date_before" type="string">
  Inclusive upper bound for `bet_end_date`, ISO 8601 with a timezone (for example `2026-11-01T00:00:00Z`). Events without `bet_end_date` are excluded. Combines with the list status window: open and pending resolution, unless `live`, `resolved_only`, or `pending_resolution` is set.
</ParamField>

<ParamField query="categories" type="integer[]">
  Comma-separated category IDs. A root category includes its descendants. An event matches any listed category.
</ParamField>

<ParamField query="category_slug" type="string[]">
  Optional comma-separated category slugs, as an alternative to `categories`. A root slug includes its descendants. An event matches any listed slug. When `categories` is also set, the event must match both.
</ParamField>

<ParamField query="currency_mode" type="string" default="play_money">
  Filter by currency mode. One of `play_money` or `real_money`.
</ParamField>

<ParamField query="hide_my_bets" type="boolean" default="false">
  Authenticated only. When `true`, excludes events where you have active bets.
</ParamField>

<ParamField query="live" type="boolean" default="false">
  When `true`, returns events that are live now or start within 12 hours.
</ParamField>

<ParamField query="only_markets_i_follow" type="boolean" default="false">
  Authenticated only. When `true`, returns only events the user follows.
</ParamField>

<ParamField query="pending_resolution" type="boolean" default="false">
  When `true`, returns unresolved events whose close time has passed.
</ParamField>

<ParamField query="resolved_only" type="boolean" default="false">
  When `true`, returns only resolved events.
</ParamField>

<ParamField query="search" type="string">
  Case-insensitive search across the event title, market names, categories, and tags. Between 1 and 100 characters.
</ParamField>

<ParamField query="tag" type="string[]">
  Comma-separated tag slug or name, up to 10. An event matches if it has any listed tag. Matching is case-insensitive. A name follows the request language; a slug does not.
</ParamField>

<ParamField query="ordering" type="string">
  Field to sort results by. Allowed values: `relevance`, `-relevance`, `created_on`, `-created_on`, `bet_end_date`, `-bet_end_date`, `wagers_count`, `-wagers_count`, `volume`, `-volume`, `open_date`, `-open_date`, `resolve_date`, `-resolve_date`. Prefix with `-` for descending order.
</ParamField>

<ParamField query="limit" type="integer">
  Number of results to return per page.
</ParamField>

<ParamField query="offset" type="integer">
  The initial index from which to return the results.
</ParamField>

## Response

Returns a paginated list of events.

<ResponseField name="count" type="integer" required>
  Total number of events matching the query.
</ResponseField>

<ResponseField name="next" type="string">
  URL for the next page of results, or `null` if there are no more pages.
</ResponseField>

<ResponseField name="previous" type="string">
  URL for the previous page of results, or `null` if on the first page.
</ResponseField>

<ResponseField name="results" type="object[]" required>
  Array of event objects.
</ResponseField>

## Example

<CodeGroup>

```bash cURL
curl -G "https://api.futuur.com/v2.0/events/" \
  --data-urlencode "currency_mode=play_money" \
  --data-urlencode "search=bitcoin" \
  --data-urlencode "ordering=-volume" \
  --data-urlencode "limit=10"
```

```python Python
import requests

response = requests.get(
    "https://api.futuur.com/v2.0/events/",
    params={
        "currency_mode": "play_money",
        "search": "bitcoin",
        "ordering": "-volume",
        "limit": 10,
    },
)

events = response.json()
for event in events["results"]:
    print(event["title"])
```
