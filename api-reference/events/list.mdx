---
title: "List events"
description: "Retrieve a paginated list of prediction market events with optional filters."
---

Retrieve a list of prediction market events. Filter by category, tag, search term, currency mode, date range, and status. Results are paginated.

## Endpoint

```
GET https://api.futuur.com/v2.0/events/
```

## Authentication

<Note>
  This endpoint does not require authentication. Public event data is accessible without HMAC headers.
</Note>

## Parameters

<ParamField query="search" type="string">
  Case-insensitive search across the event title, market names, categories, and tags. Maximum 100 characters.
</ParamField>

<ParamField query="categories" type="string">
  Comma-separated category IDs. A root category includes its descendants. An event matches any listed category.
</ParamField>

<ParamField query="category_slug" type="string">
  Comma-separated category slugs, as an alternative to `categories`. A root slug includes its descendants. An event matches any listed slug. When `categories` is also set, the event must match both.
</ParamField>

<ParamField query="tag" type="string">
  Comma-separated tag slug or name, up to 10. An event matches if it has any listed tag. Matching is case-insensitive.
</ParamField>

<ParamField query="currency_mode" type="string" default="play_money">
  Filter by currency mode: `play_money` or `real_money`. Defaults to `play_money`.
</ParamField>

<ParamField query="bet_end_date_after" type="string">
  Inclusive lower bound for `bet_end_date`, ISO 8601 with timezone (e.g., `2026-11-01T00:00:00Z`). Events without `bet_end_date` are excluded. Combines with the list status window: open and pending resolution, unless `live`, `resolved_only`, or `pending_resolution` is set.
</ParamField>

<ParamField query="bet_end_date_before" type="string">
  Inclusive upper bound for `bet_end_date`, ISO 8601 with timezone (e.g., `2026-11-01T00:00:00Z`). Events without `bet_end_date` are excluded. Combines with the list status window: open and pending resolution, unless `live`, `resolved_only`, or `pending_resolution` is set.
</ParamField>

<ParamField query="live" type="boolean" default="false">
  When `true`, return events that are live now or start within 12 hours.
</ParamField>

<ParamField query="resolved_only" type="boolean" default="false">
  When `true`, return only resolved events.
</ParamField>

<ParamField query="pending_resolution" type="boolean" default="false">
  When `true`, return unresolved events whose close time has passed.
</ParamField>

<ParamField query="hide_my_bets" type="boolean" default="false">
  Authenticated only. Omit events the user has already bet on.
</ParamField>

<ParamField query="only_markets_i_follow" type="boolean" default="false">
  Authenticated only. Return only events the user follows.
</ParamField>

<ParamField query="ordering" type="string">
  Field to order results by. Allowed values: `relevance`, `-relevance`, `created_on`, `-created_on`, `bet_end_date`, `-bet_end_date`, `wagers_count`, `-wagers_count`, `volume`, `-volume`, `open_date`, `-open_date`, `resolve_date`, `-resolve_date`. Prefix with `-` for descending order.
</ParamField>

<ParamField query="limit" type="integer">
  Number of results to return per page.
</ParamField>

<ParamField query="offset" type="integer">
  The initial index from which to return results (for pagination).
</ParamField>

## Response

Returns a paginated list of event objects.

<ResponseField name="count" type="integer" required>
  Total number of events matching the query.
</ResponseField>

<ResponseField name="next" type="string">
  URL for the next page of results, or `null` if there are no more pages.
</ResponseField>

<ResponseField name="previous" type="string">
  URL for the previous page of results, or `null` if on the first page.
</ResponseField>

<ResponseField name="results" type="array" required>
  Array of event objects.
  <Expandable title="Event object properties">
    <ResponseField name="id" type="integer" required>
      Unique event identifier.
    </ResponseField>
    <ResponseField name="title" type="string" required>
      The event title or question.
    </ResponseField>
    <ResponseField name="markets" type="array" required>
      Array of market (outcome) objects for this event.
    </ResponseField>
    <ResponseField name="bet_end_date" type="string">
      ISO 8601 timestamp when betting closes, or `null` if not set.
    </ResponseField>
    <ResponseField name="categories" type="array">
      Array of category objects the event belongs to.
    </ResponseField>
    <ResponseField name="tags" type="array">
      Array of tag objects associated with the event.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>

```python python
import requests

response = requests.get(
    "https://api.futuur.com/v2.0/events/",
    params={
        "search": "US election",
        "currency_mode": "play_money",
        "ordering": "-volume",
        "limit": 10,
    },
)

data = response.json()
for event in data["results"]:
    print(event["id"], event["title"])
```

```bash curl
curl -G "https://api.futuur.com/v2.0/events/" \
  --data-urlencode "search=US election" \
  --data-urlencode "currency_mode=play_money" \
  --data-urlencode "ordering=-volume" \
  --data-urlencode "limit=10"
```
