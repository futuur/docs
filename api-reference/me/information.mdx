---
title: "Account information"
description: "Retrieve your account details and wallet balances."
---

Returns details about your authenticated account, including your username, email address, wallet balances, and account status.

For ledger balances broken out by currency, use [`GET /me/balances/`](/api-reference/me/balances).

## Endpoint

```
GET https://api.futuur.com/v2.0/me/
```

## Authentication

This endpoint requires HMAC-SHA512 authentication. Include the following headers with every request:

| Header | Description |
|--------|-------------|
| `Key` | Your public API key |
| `Timestamp` | Current Unix timestamp |
| `HMAC` | SHA-512 signature of the request |

## Parameters

This endpoint takes no parameters.

## Response

Returns a `UserPrivate` object.

<ResponseField name="id" type="integer" required>
  Unique numeric identifier for your account.
</ResponseField>

<ResponseField name="username" type="string">
  Your account username.
</ResponseField>

<ResponseField name="email" type="string" required>
  The email address associated with your account.
</ResponseField>

<ResponseField name="wallet" type="object" required>
  Dictionary of balances keyed by currency code (for example, `OOM`, `USDC`, `USDT`, `USD`). Values are decimal strings.
</ResponseField>

<ResponseField name="email_confirmed" type="boolean" required>
  Whether you have confirmed your email address.
</ResponseField>

<ResponseField name="real_currency_enabled" type="boolean" required>
  Whether real money trading is enabled for your account.
</ResponseField>

<ResponseField name="kyc_status" type="string" required>
  Current KYC status. One of `no_need`, `requested`, `initialized`, `refused`, `approved`, or `by_passed`.
</ResponseField>

<ResponseField name="date_joined" type="string">
  ISO 8601 timestamp of when you joined Futuur.
</ResponseField>

## Register a Safe address

If you use a [Safe](https://safe.global) smart account, register it with Futuur by calling [`POST /me/safe/`](/api-reference/me/safe). The request body requires both a `safe_address` and a `chain_id`. On success, the response is the same `UserPrivate` object returned by `GET /me/`.

## Example

```bash
curl --request GET \
  --url https://api.futuur.com/v2.0/me/ \
  --header 'Key: YOUR_PUBLIC_KEY' \
  --header 'Timestamp: 1712345678' \
  --header 'HMAC: YOUR_HMAC_SIGNATURE'
```
