Aqui você pode encontrar todas as informações relevantes sobre como os passos para acessar nossa API.

## Vocês têm uma API pública? Como posso usá-la?

Sim! Você pode visualizar a documentação da nossa API aqui: [https://docs.futuur.com](/introduction)

Para gerar uma chave privada e começar a usar a API, por favor, vá para sua [página de Configurações](https://futuur.com/a/settings).

Se tiver perguntas, sugestões ou qualquer outro feedback sobre a API, por favor, entre em contato com [support@futuur.com](mailto:support@futuur.com).
