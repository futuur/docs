---

The [Model Context Protocol](https://modelcontextprotocol.io) (MCP) lets AI assistants like Claude call external tools on your behalf. The Futuur MCP server exposes tools covering market discovery, order placement, position management, and account info — all accessible through natural language.

**You can say things like:**
- *"Show me the top 10 markets by volume"*
- *"Simulate buying 200 OOM on the Yes outcome of event #1234"*
- *"What are my open positions and how are they performing?"*
- *"Sell 50 shares of my wager on the US election market"*

---

## Prerequisites

<Steps>
  <Step title="Node.js 18 or higher">
    Download from [nodejs.org](https://nodejs.org). Verify with `node --version`.
  </Step>
  <Step title="Futuur API keys">
    Log in to [futuur.com](https://futuur.com) → **Settings** → **API** → generate a key pair. You'll get a **public key** and a **private key**.
  </Step>
</Steps>

## Setup

Paste your keys below to get a ready-to-copy config for your client.

export function ConfigBuilder() {
  const [pub, setPub] = React.useState('');
  const [priv, setPriv] = React.useState('');
  const [copied, setCopied] = React.useState(null);

  const pk = pub.trim() || 'YOUR_PUBLIC_KEY';
  const sk = priv.trim() || 'YOUR_PRIVATE_KEY';
  const filled = pub.trim() !== '' && priv.trim() !== '';

  const config = JSON.stringify(
    { mcpServers: { futuur: { command: 'npx', args: ['-y', '@futuur/futuur-mcp'], env: { FUTUUR_PUBLIC_KEY: pk, FUTUUR_PRIVATE_KEY: sk } } } },
    null, 2
  );

  const copy = (text, id) => {
    navigator.clipboard.writeText(text).then(() => {
      setCopied(id);
      setTimeout(() => setCopied(null), 2000);
    });
  };

  const inputStyle = {
    width: '100%', padding: '8px 12px', borderRadius: '8px',
    border: '1px solid #d1d5db', fontFamily: 'monospace', fontSize: '13px',
    background: 'var(--background-color, #fff)', color: 'inherit',
    outline: 'none', boxSizing: 'border-box',
  };
  const labelStyle = { display: 'block', fontSize: '13px', fontWeight: 600, marginBottom: '6px', color: 'inherit' };
  const blockStyle = { position: 'relative', background: 'var(--code-background, #0f1117)', borderRadius: '8px', padding: '16px', overflow: 'auto' };
  const preStyle = { margin: 0, fontFamily: 'monospace', fontSize: '12px', color: '#e2e8f0', whiteSpace: 'pre', lineHeight: 1.6 };
  const copyBtnStyle = {
    position: 'absolute', top: '10px', right: '10px',
    padding: '4px 10px', fontSize: '11px', borderRadius: '6px', border: 'none',
    background: '#374151', color: '#f9fafb', cursor: 'pointer', fontWeight: 500,
  };
  const sectionTitleStyle = { fontSize: '13px', fontWeight: 700, marginBottom: '8px', marginTop: '16px', color: 'inherit' };
  const hintStyle = { fontWeight: 400, color: '#6b7280', marginLeft: '6px', fontSize: '12px' };
  const badgeStyle = (ok) => ({
    display: 'inline-block', width: '8px', height: '8px', borderRadius: '50%',
    background: ok ? '#22c55e' : '#9ca3af', marginRight: '6px',
  });

  return (
    <div style={{ border: '1px solid #e5e7eb', borderRadius: '12px', padding: '20px', marginBottom: '24px' }}>
      <div style={{ display: 'grid', gridTemplateColumns: '1fr 1fr', gap: '12px', marginBottom: '20px' }}>
        <div>
          <label style={labelStyle}>Public key</label>
          <input style={inputStyle} value={pub} onChange={e => setPub(e.target.value)} placeholder="paste your public key" spellCheck={false} />
        </div>
        <div>
          <label style={labelStyle}>Private key</label>
          <input style={inputStyle} type="password" value={priv} onChange={e => setPriv(e.target.value)} placeholder="paste your private key" spellCheck={false} />
        </div>
      </div>

      {!filled && (
        <p style={{ fontSize: '12px', color: '#9ca3af', marginBottom: '16px', marginTop: 0 }}>
          Enter your keys above to get personalised configs you can paste directly.
        </p>
      )}

      <div>
        <div style={sectionTitleStyle}>
          <span style={badgeStyle(filled)} />
          Claude Desktop
          <span style={hintStyle}>~/Library/Application Support/Claude/claude_desktop_config.json (macOS) · %APPDATA%\Claude\claude_desktop_config.json (Windows)</span>
        </div>
        <div style={blockStyle}>
          <pre style={preStyle}>{config}</pre>
          <button style={copyBtnStyle} onClick={() => copy(config, 'desktop')}>
            {copied === 'desktop' ? '✓ Copied' : 'Copy'}
          </button>
        </div>
      </div>

      <div>
        <div style={sectionTitleStyle}>
          <span style={badgeStyle(filled)} />
          Claude Code
          <span style={hintStyle}>~/.claude.json · or project .claude/settings.json</span>
        </div>
        <div style={blockStyle}>
          <pre style={preStyle}>{config}</pre>
          <button style={copyBtnStyle} onClick={() => copy(config, 'code')}>
            {copied === 'code' ? '✓ Copied' : 'Copy'}
          </button>
        </div>
      </div>

      <div>
        <div style={sectionTitleStyle}>
          <span style={badgeStyle(filled)} />
          Cursor
          <span style={hintStyle}>.cursor/mcp.json in your project · or global Cursor settings</span>
        </div>
        <div style={blockStyle}>
          <pre style={preStyle}>{config}</pre>
          <button style={copyBtnStyle} onClick={() => copy(config, 'cursor')}>
            {copied === 'cursor' ? '✓ Copied' : 'Copy'}
          </button>
        </div>
      </div>

      <p style={{ fontSize: '11px', color: '#9ca3af', marginTop: '14px', marginBottom: 0 }}>
        Your keys are never sent anywhere — they stay in your browser and go directly into the config you copy.
      </p>
    </div>
  );
}

After pasting the config, **restart your client** (Claude Desktop and Cursor require a full restart to pick up MCP servers).

## Available tools

<CardGroup cols={2}>
  <Card title="Market discovery" icon="magnifying-glass">
    `get_markets` · `get_market_details` · `get_price_history` · `get_categories`
  </Card>
  <Card title="Account" icon="user">
    `get_user_profile` · `get_user_ranking`
  </Card>
  <Card title="Trading" icon="arrow-right-arrow-left">
    `get_bet_simulation` · `place_bet` · `list_orders` · `cancel_order`
  </Card>
  <Card title="Positions" icon="chart-line">
    `get_user_bets` · `get_wager_details` · `get_partial_sell_amount` · `sell_bet`
  </Card>
</CardGroup>

| Tool | What it does |
|------|-------------|
| `get_markets` | List and search events with filters — category, tag, status, ordering |
| `get_market_details` | Full details for one event including all outcome markets |
| `get_price_history` | Historical prices for an event (`day` / `week` / `month` / `year` / `all_time`) |
| `get_categories` | List available market categories |
| `get_user_profile` | Your account profile and balances |
| `get_user_ranking` | Your leaderboard position |
| `get_bet_simulation` | Preview a buy order — cost and shares — without placing it |
| `place_bet` | Execute a limit order from a confirmed simulation |
| `list_orders` | List your open, filled, or cancelled orders |
| `cancel_order` | Cancel an open order by ID |
| `get_user_bets` | List your wager positions with filters |
| `get_wager_details` | Full details for one wager |
| `get_partial_sell_amount` | Simulate how much you'd receive for selling N shares |
| `sell_bet` | Sell all or part of a wager position |

## Example session

```
You:    Show me the top 5 prediction markets right now

Claude: [calls get_markets with ordering=-volume, limit=5]
        Here are the top markets by volume: ...

You:    I want to bet 100 OOM that Trump wins. Show me the details first.

Claude: [calls get_market_details for the event]
        The "Trump wins 2026" market is currently priced at 62% (0.62).
        Market ID: 8821, Event ID: 4401.

You:    Simulate buying 100 OOM on the Yes outcome

Claude: [calls get_bet_simulation with event_id=4401, market=8821, amount=100, currency=OOM]
        You'd receive approximately 161 shares at 0.62 each. Total cost: 100 OOM.
        Shall I place the order?

You:    Yes, go ahead

Claude: [calls place_bet with confirmed payload]
        Order placed. ID: 99231, status: filled.
```

<Tip>
  Use `currency_mode: "play_money"` to practice with OOM (play money) before trading real funds.
</Tip>
