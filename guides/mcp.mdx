The [Model Context Protocol](https://modelcontextprotocol.io) (MCP) lets Claude call external tools on your behalf. The Futuur MCP server exposes tools covering market discovery, order placement, position management, and account info — all accessible through natural language.

**Get connected in under a minute:** paste your API keys, copy the `claude mcp add` command, run it in your terminal, then start a new Claude session.

**You can say things like:**
- *"Show me the top 10 markets by volume"*
- *"Simulate spending 200 OOM on Yes in the Bitcoin market"*
- *"What are my open positions and how are they performing?"*
- *"Sell 50 shares of my wager on the US election market"*

## Prerequisites

<Steps>
  <Step title="Node.js 20 or higher">
    Download from [nodejs.org](https://nodejs.org). Verify with `node --version`.
  </Step>
  <Step title="Claude Code CLI">
    Install the [Claude Code CLI](https://docs.anthropic.com/en/docs/claude-code). Verify with `claude --version`.
  </Step>
  <Step title="Futuur API keys">
    Log in to [futuur.com](https://futuur.com) → **Settings** → **API keys** → generate a key pair. You'll get a **public key** and a **private key**. See [Get your API keys](/guides/get-api-keys).
  </Step>
</Steps>

## Setup

Paste your Futuur API keys below, then copy and run the generated command in your terminal.

<McpConfigBuilder />

<Steps>
  <Step title="Paste your API keys">
    Use the fields above. Keys stay in your browser — they are only embedded in the command you copy.
  </Step>
  <Step title="Copy and run">
    Paste the `claude mcp add` command into your terminal and press Enter. Claude registers the Futuur MCP server with your keys.
  </Step>
  <Step title="Start Claude">
    Open a new Claude Code session (`claude`) — the Futuur tools are available immediately.
  </Step>
</Steps>

<Tip>
  To add the server for a single project only, run the command from that project directory. To add it globally, run it from any directory — Claude stores it in your user config.
</Tip>

<Accordion title="Manual JSON config (optional)">
  If you prefer to edit config files yourself, add this under `"mcpServers"` in `~/.claude.json` (global) or `.claude/settings.json` (project):

  ```json
  {
    "futuur": {
      "command": "npx",
      "args": ["-y", "@futuur/futuur-mcp"],
      "env": {
        "FUTUUR_PUBLIC_KEY": "your_public_key_here",
        "FUTUUR_PRIVATE_KEY": "your_private_key_here"
      }
    }
  }
  ```
</Accordion>

## Available tools

Market data tools work without API keys. Account and trading tools need them.

<CardGroup cols={2}>
  <Card title="Market discovery" icon="search">
    `get_markets` · `get_market_details` · `get_price_history` · `get_order_book` · `get_categories` · `get_category_details`
  </Card>
  <Card title="Account" icon="user">
    `get_user_profile` · `get_balances` · `get_user_ranking`
  </Card>
  <Card title="Trading" icon="arrow-left-right">
    `get_bet_simulation` · `place_bet` · `list_orders` · `cancel_order` · `cancel_all_orders`
  </Card>
  <Card title="Positions" icon="chart-line">
    `get_user_bets` · `get_wager_details` · `get_partial_sell_amount` · `sell_bet`
  </Card>
</CardGroup>

| Tool | What it does |
|------|-------------|
| `get_markets` | List and search events with filters: category, tag, status, close date, ordering |
| `get_market_details` | Full details for one event including all outcome markets |
| `get_price_history` | Historical prices for an event (`day` / `week` / `month` / `year` / `all_time`) |
| `get_order_book` | Bids and asks for one market |
| `get_categories` · `get_category_details` | Browse market categories |
| `get_exchange_rates` · `convert_to_usd` · `convert_from_usd` | Currency rates and indicative conversions |
| `get_user_profile` | Your account profile |
| `get_balances` | Your balance per currency (see also [`GET /me/balances/`](/api-reference/me/balances)) |
| `get_user_ranking` | Your leaderboard position |
| `get_bet_simulation` | Preview a buy or sell against the live order book, without placing it |
| `place_bet` | Place a limit or market order |
| `list_orders` | List your open, filled, or cancelled orders |
| `cancel_order` · `cancel_all_orders` | Cancel one open order, or all of them on a market or event |
| `get_user_bets` | List your wager positions with filters |
| `get_wager_details` | Full details for one wager |
| `get_partial_sell_amount` | Estimate what a position would sell for |
| `sell_bet` | Sell all or part of a wager position |

Tools that move your balance (`place_bet`, `sell_bet`, `cancel_order`, `cancel_all_orders`) are marked as such, so Claude asks before running them.

## Example session

```
You:    Show me the top 5 prediction markets right now

Claude: [calls get_markets with ordering=-volume, limit=5]
        Here are the top markets by volume: ...

You:    I want to bet 100 OOM that Trump wins. Show me the details first.

Claude: [calls get_market_details for the event]
        The "Trump wins 2026" market is currently priced at 62% (0.62).
        Market ID: 8821, Event ID: 4401.

You:    Simulate spending 100 OOM on the Yes outcome

Claude: [calls get_bet_simulation with market=8821, side=bid, position=long, currency=OOM, amount=100]
        That buys about 161 shares at an average price of 0.62, for 100 OOM.
        Shall I place the order?

You:    Yes, go ahead

Claude: [calls place_bet with market=8821, side=bid, position=long, currency=OOM, shares=161]
        Order placed. ID: 99231, status: filled.
```

<Tip>
  Trade with `currency: "OOM"` (play money) to practice before using real funds.
</Tip>
