Here you can find all the relevant information on how to access our API.

## Do you have a public API? How can I use it?

Yes! You can view our API documentation here: [https://docs.futuur.com](/introduction)

To generate an API key and start using the API, please go to your **Settings** page: [https://futuur.com/a/settings](https://futuur.com/a/settings)

If you have any questions, suggestions, or other feedback about the API, please contact us at **[support@futuur.com](mailto:support@futuur.com)**.
