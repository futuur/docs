Using a coupon code on Futuur takes just a few seconds. Read on to learn how to do it and which rules apply.

## How do I use a Coupon Code?

1. **Open the Account Menu**<br />
   Click on your profile icon in the top-right corner of the screen
2. **Click “Redeem a code”**<br />
   In the dropdown menu, select **“Redeem a code.”**
3. **Enter Your Code**
4. **Click “Redeem”**<br />
   Click the **Redeem** button to apply the code to your account. If the code is valid, the bonus will be instantly credited to your Futuur balance.

## Coupon Code Rules

- **The bonus is locked until you have bet in enough different markets and those markets have resolved.** The number is set by each promotion and is usually 5.
- **Different markets, not number of bets.** Several bets in the same market count as one market. Five bets in one market count as 1, not 5.
- **The market must be resolved.** A market counts once it has been resolved and your bet there was settled as won or lost. Bets in markets that are still open, or that were cancelled, do not count yet.
- **Only bets placed after you redeem the code count**, and only bets in the same currency as the bonus.
- **Only the bonus amount is locked.** You can withdraw the rest of your balance at any time, including your own deposits and any winnings above the bonus amount.
- **One code at a time.** You can redeem a new code only after the previous one has met its requirement.
- A code stops working after its promotion's end date, if it has one.
